L’écosystème Python scientifique

La boîte à outils du cours en détail

Ce cours s’appuie sur huit bibliothèques open source, gratuites, et qui ensemble couvrent à peu près toute l’analyse de données scientifique en Python. Cette page les présente une par une : à quoi elles servent, qui les maintient, et où aller pour en apprendre davantage.

AstuceConseil de lecture

Lisez cette page avant de commencer le Module 1. Vous comprendrez mieux pourquoi on importe chaque bibliothèque et ce qu’elle apporte. Revenez-y quand vous voulez en approfondir une.

Le socle scientifique

Trois bibliothèques constituent le socle sur lequel tout le reste est construit. Apprendre Python pour la science, c’est d’abord apprendre ces trois-là.

SOCLE

NumPy

NumPy (Numerical Python) fournit les tableaux multidimensionnels performants (ndarray) sur lesquels tout le reste de l’écosystème scientifique est construit. C’est l’équivalent en Python d’un MATLAB ou d’un R sur le plan numérique brut.

Utilisé dans : tous les modules (en arrière-plan de pandas)
Docs : numpy.org/doc
Tutoriel débutant : NumPy Quickstart
Mainteneur : NumFOCUS, sponsorisé par CZI, Tidelift, Quansight

SOCLE

pandas

pandas est la bibliothèque de manipulation de tables (DataFrame, Series) en Python. Pensez « Excel programmable et 1000× plus puissant ». C’est avec elle que vous chargerez, filtrerez, grouperez et nettoierez vos données cliniques tout au long du cours.

Utilisé dans : tous les modules
Docs : pandas.pydata.org
Tutoriel : 10 minutes to pandas · Cours intensif Kaggle
Mainteneur : Wes McKinney + NumFOCUS

SOCLE

Matplotlib

Matplotlib est la bibliothèque de visualisation fondamentale de Python. Toute autre lib de plot (seaborn, plotly, pandas.plot) en dépend ou s’en inspire. API verbose mais maximale flexibilité — quand vous voulez exactement le graphique de votre publication.

Utilisé dans : tous les modules
Docs : matplotlib.org
Tutoriel : Gallery officielle · Cheat sheets
Mainteneur : John Hunter (†) + NumFOCUS

Statistique et visualisation avancée

Trois bibliothèques par-dessus le socle pour la statistique inférentielle et la visualisation statistique haut-niveau.

VIZ

seaborn

seaborn est une couche statistique au-dessus de matplotlib. Quand vous voulez « le boxplot par groupe en une ligne », c’est elle. Inspirée de ggplot2 (R), avec des thèmes propres et une intégration native pandas.

Utilisé dans : Modules 3, 4, 5, 6
Docs : seaborn.pydata.org
Tutoriel : Tutorial officiel · Gallery
Mainteneur : Michael Waskom

STATS

SciPy

SciPy rassemble la boîte à outils scientifique générale : tests statistiques (scipy.stats), optimisation, traitement du signal, algèbre linéaire de plus haut niveau, etc. Vous utiliserez surtout scipy.stats pour les t-test, χ², Mann-Whitney et lois de probabilité.

Utilisé dans : Modules 2, 3, 4, 5, 6
Docs : docs.scipy.org
Tutoriel : Statistics tutorial
Mainteneur : NumFOCUS

STATS

statsmodels

statsmodels est la bibliothèque de modèles statistiques inférentiels en Python — analogue à R en termes de richesse. Régression OLS, GLM (dont logistique), modèles mixtes, série temporelle, tests de Wald. Sortie en tableau de résultats à la summary() familier aux utilisateurs R.

Utilisé dans : Modules 4, 5, 6
Docs : statsmodels.org
Tutoriel : User Guide · Notebooks d’exemples
Mainteneur : NumFOCUS
Compatibilité : exige >= 0.14.6 avec scipy >= 1.17

Machine learning et analyse de survie

ML

scikit-learn

scikit-learn est la bibliothèque de machine learning « classique » de Python. API uniforme (fit, predict, score, transform), des dizaines d’algorithmes (régression, classification, clustering, réduction de dimension), pipelines, validation croisée, métriques. Vous l’utiliserez pour les forêts aléatoires et l’évaluation ROC/calibration.

Utilisé dans : Modules 5, 6
Docs : scikit-learn.org
Tutoriel : User Guide · Glossary
Livre gratuit : Introduction to Statistical Learning (édition Python)
Mainteneur : INRIA + NumFOCUS

SURVIE

lifelines

lifelines est la bibliothèque dédiée à l’analyse de survie en Python — Kaplan-Meier, Cox PH, modèles paramétriques (Weibull, log-logistique, etc.), tests log-rank. Indispensable pour les essais cliniques, les cohortes longitudinales et toute analyse « temps avant événement ».

Utilisé dans : Module 5 (intro Cox)
Docs : lifelines.readthedocs.io
Tutoriel : Survival analysis intro
Mainteneur : Cameron Davidson-Pilon

L’environnement de travail

Deux outils qui ne sont pas des bibliothèques mais qui font la différence.

ENV

Jupyter / JupyterLab

L’environnement de notebook interactif standard. Mélange texte (Markdown), code, sorties (tableaux, figures, animations) dans un même document exécutable. C’est le format de la science computationnelle moderne.

Docs : jupyter.org/documentation
Mode d’emploi : Notebook Basics
Mainteneur : Projet Jupyter (Fernando Pérez et al.) + NumFOCUS

ENV

Google Colab

Plateforme cloud qui exécute des notebooks Jupyter gratuitement avec toutes les bibliothèques scientifiques préinstallées. Aucune installation, GPU gratuit pour les tâches modérées. C’est la façon recommandée de suivre ce cours.

Lancer un module : badges Open In Colab sur la page d’accueil ou en haut de chaque notebook
Tutoriel : Notebook d’intro Colab
Mainteneur : Google
